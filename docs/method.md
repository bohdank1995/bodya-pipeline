# Method

## The loop

Every pipeline uses the same loop, from Eric Ries' *The Lean Startup*:

1. **Hypothesis**: one belief, written so it can be wrong.
2. **Build**: the smallest thing that tests it (a search, a post, a page, a script, a prototype).
3. **Measure**: one key metric, compared with a success bar set *before* the test.
4. **Learn**: what the result means.
5. **Decide**:
   - *Persevere*: the bar was met, so go to the next lap or the next pipeline.
   - *Pivot*: the bar was missed, so write a new hypothesis.
   - *Stop*: the idea isn't worth another lap.
6. **Share**: an X post and/or a portfolio case study.

## Rules

- **One experiment answers one question.** If a card has two questions, split it into two experiments.
- **Set the success bar before you start**, as a number and a deadline. Never move it afterwards.
- **Time-box every experiment.** When the time runs out, decide with the data you have.
- **Tie it to profit.** Name the lever: traffic, conversion, price, retention or cost.
- **Behavior beats opinion.** What people say < what they do < what they pay.
- **A failed experiment is still a finished experiment.** It gets a Learning Card and is shared like any other.

## Sources

- Eric Ries, *The Lean Startup*: the Build → Measure → Learn loop, and the pivot-or-persevere decision.
- David Bland & Alex Osterwalder, *Testing Business Ideas* (Strategyzer): the Test Card and Learning Card formats.
- Rob Fitzpatrick, *The Mom Test*: interview questions about past behavior, not opinions.
- Sean Ellis, *Hacking Growth*: ICE scoring (Impact, Confidence, Ease) for choosing the next experiment.
- swyx, "Learn in Public", and Austin Kleon, *Show Your Work*: sharing the process, not only the results.
